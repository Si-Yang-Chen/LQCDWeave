# 整体介子值的完整 cfg 身份

同一个整体介子数值可出现在多个 Term 中；这些出现位置共享结果名字，也必须共享同一个
完整 cfg 数值 owner。`cfg_plan` 对原生 `MesonWholeKernel` 使用实际有序输入 ID、完整
`kernel.identity`、保存的局部路径及宽累加标记确定数值身份。核身份包含规范化的完整私有方程
（含输出顺序）、connected/loop 类型、表示、坐标 lane 和中立实现声明；实际输入 ID 已绑定
当前准备值及其规格。Term 编号、positions 和逻辑顶点名字只定位证明出现位置，不产生新 owner。

绑定模板时，同一规则同时用于全局计算 ID 和局部重复值证明，重复出现不会覆盖结果名字后
遗留另一个无人生产的旧 ID。主机/设备生命周期继续消费原有最后使用记录；不删除释放事件，
不放宽“释放必须已驻留”的要求。普通 dense、FWR、扩展 Action 和其它特殊操作保留各自原有身份规则，
整体介子分支不访问 FWR 专用的 `core.equation`。

回归测试 `tests/correlator/planning/test_cfg_whole_meson_identity.py` 同时覆盖 connected/loop、
complex64/complex128、正常/debug 绑定，检查所有释放 ID 都有模板绑定。测试将同一整体值放入
三个 Term，在重复与不同时间坐标上保存并读取完整档案，再绑定两个 cfg 的当前输入，逐项对照
完整私有指标方程的独立 NumPy 收缩。身份单测另外区分输入顺序、输出布局、表示、lane、
核实现、局部路径与精度标记，并确认指标重命名和证明位置改变不破坏复用。
