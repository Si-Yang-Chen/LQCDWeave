# 存储元素、空间核算与排名成本

存储排期的一个元素仍是一次已选缩并及其共享更新：先读取和准备当前缺少的输入，再消费已登记的
输出大小和 kernel workspace，最后释放本次完成最后使用的数据。host/device 驻留字节与逻辑张量、
物理块的剩余引用数增量维护；DFS 撤销只恢复本步改动。这里不重新定价内核，不增加 recompute、
spill、读取次数或前端选项，也不改变逻辑搜索及并行根分支。

释放排名的传递依赖 mask 在首次真正需要排名时构造。正常候选直接求 `ready_mask & target.required`；先把同一
完整 mask 展开成所有位置再复制，属于重复工作。原释放优先级、整数交叉比较、ready 次序、DFS、
两个内存域的准入规则及已有原顺序兜底均保持。资源轨迹发射不需要释放排名，因此不构造这套索引；
需要排名时，同一 DAG 的 mask 只构造一次，跨查询和 undo 复用。
