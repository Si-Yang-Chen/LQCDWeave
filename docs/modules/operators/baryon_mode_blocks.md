# 重子关联函数的本征模分块

`S.api.split_baryon_eigenmodes(correlator, *, partitions)` 为重子 Diagram 建立三夸克空间模态分块。它递归处理关联函数结构；每个 `(time, vertex)` 追加三条模式轴，轴按 `(time, vertex)` 排列，顶点内固定为 Baryon 原始空间槽 0、1、2。源端 dagger 不交换这三条空间轴。传播子端点仍通过 `field_order=(2,1,0)` 映射源夸克槽；这个传播子字段顺序不改变 elemental 模式轴顺序。

`B.with_mode_indices` 保存按原始空间槽给出的选择。VVV elemental 和 VSV propagator 的读取都必须消费实际 `mode_indices`，而不是仅记录选择或读取共同前缀。该分块沿用现有 `BaryonDiagramBinding` 和优化器。

## 全对称径向三元组

`S.api.project_baryon_mode_triples(blocks, *, mode_axis=0, vertices=2)` 对每个模式三元组的不同 S3 排列作全对称组合，并除以 `sqrt(m)`。其中 `m` 是不同排列数：三个索引相同为 1，恰有两个相同为 3，三个都不同时为 6。径向索引按 `a <= b <= c` 的字典序排列。将每个径向块乘回 `sqrt(m)` 后求和，可恢复全部有序块之和。

四个分区产生每顶点 64 个有序三元组，径向投影后为 20 个三元组。标量两点函数的六条有序模式轴形状为 `4^6`，两端投影后为 `20×20`。

全对称径向投影保留既有 spin-flavor-space 交换类型。重子没有介子的 C 本征分区；若需解析非对称 S3 径向分量，必须将模式置换与 spin/flavor 空间投影联动，当前不在此接口范围内。介子 elemental 也不能代替含三夸克 epsilon 颜色收缩的 VVV elemental。

这里的归一化是不同有序分块的组合系数归一化，并不保证算符具有单位物理范数。
Pauli 约束可能使某些组合为零或线性相关；20 个候选不保证对应 20 个独立态。
共同划分应随空间对称变换一致，并保留严格简并的完整本征子空间。

## 时间反射

反射分析涉及反重子及相应的相反宇称，不能直接照搬介子同一 PC 扇区的反射平均。
在零化学势、标准反周期边界及 Dirac 宇称投影约定下，
`G_±(t) = -G_∓(Lt-t)`；该式使用 `bar(O)=O† gamma4` 的定义。
任意自旋行和算符矩阵还需核对共轭映射及相位，不能直接将脚本的 g/u 数组代入。
来源见 [Aarts 等，§2.4](https://arxiv.org/html/1703.09246#S2.SS4)。
分块接口不实施反射平均。

## 范围与验收边界

当前范围限于等时、纯重子 dense VVV/VSV 和固定时间对；时间扫描不支持。
输入为 Diagram 表达式及其字典、列表、元组或数组；生成时使用
`gen_correlator(..., structured=False)`。StructuredCorrelator 输入会明确拒绝。
持久化 `run_indexed_diagram_measurement` 的科学定义尚未编码模式选择，会明确拒绝
分块图及已选择模式的 Baryon 顶点。保存任务结果时应同时记录区间、轴和投影权重，
不能将其登记成原整块算符的测量。
全部块可一次交给 `calculate`，共享原有物理输入登记、规划和执行机制。
`optimize="none"` 可核对结果，但块数及逐块调用开销明显增加；不能从介子的测时推断
重子分块总耗时接近整块，也不保证预算内 `anytime` 能给出高效计划。
`tests/test_baryon_mode_blocks.py` 的小规模合成复数 CPU 专项 9 项、15 个子测试通过，
覆盖不等宽三腿分块、源端共轭、六种源槽排列、逐块直接求和、全对称投影和整块恢复，
以及描述阶段不读数据。64 个有序块的共享读取例共读取 16 个 VVV 和 12 个传播子物理块。

全量 CPU 回归为 1540 项：24 项跳过、3 项失败、9 项错误。12 项失败/错误均可在基线
`efc30e8` 复现，未发现新增失败。GPU、真实系综及生产规模性能尚未验收。
