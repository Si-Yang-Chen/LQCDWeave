# 谱学任务

先明确粒子与反粒子、味道扇区、动量、表示行、宇称及实际算符基；未确定目标时使用[测量选择](measurement-choice.md)。不从历史课题、任务名或旧脚本继承这些选择。

## 物理定义

- 用 `Hadron/Flavor` 声明算符，必要时通过 `hadron_little_group_projection` 联合投影，再调用 `gen_correlator`。各源汇列表分别创建，保留源端共轭、味道相位与归一化。
- 非零动量按实际小群处理；静止系宇称与移动系标签的关系由投影规则决定。数据覆盖投影所需的完整动量轨道，不能只按文件槽号推断动量。
- C 变换须结合味道与空间/自旋部分核对。先判断所选味道扇区是否在 C 下闭合，再决定是否按 C 分块；不能把目录中的变换因子直接当作所有粒子的物理 C 本征值。
- 简并与非简并味道使用实际作用量和传播子。删除某类 Wick 贡献是估计量选择，必须来自用户的物理定义，不能为加速自动开启。

## 计算与复用

把全部兼容通道、表示行、方向和径向需求组成同一嵌套请求，选定一次路径后固定回放；见[计划复用](plans.md#联合任务与一次规划反复回放)。仅把符号构造移到循环外或返回 `partial(calculate, ...)` 不构成计划复用。

单强子和多强子可组成同量子数的变分算符基；每项保留各自的 `Hadron/Flavor`，由同一 `gen_correlator` 生成全部矩阵块，不能用首个算符的味结构覆盖整组，也不能只计算各自的方阵而省掉两方向交叉项。径向定义须来自任务的实际模态区间或谱权重，不能仅凭“径向激发”自行指定配方。

用户要求先给每个表示一个算符时，选择有明确空间/Dirac 定义的预制配方，并保留该表示的全部行；单个配方不额外引入径向权重。若目标需要杂化结构，明确标注相应的规范场插入及其数据需求，不能用普通局域双线性冒充。不同味道的完整模式选择经 `Meson.with_mode_indices` 沿真实端点传递，数据绑定、展示清单和计划应使用同一算符定义。

每 cfg 绑定自己的输入、实际有序基底和物理时间。逐腿截断见[基底与截断](vertex-legs.md)；同位旋伙伴、交换配对项及共轭端点的选择关系仍需核验，不能只固定 Flavor 系数后假定量子数保持。

结果保留实际通道矩阵、源汇时间、表示行和归一化；平均、过滤及重建仅按明确的测量定义执行。正式运行前按[谱学核对表](../../README.md#execution-scope)检查目标和覆盖，沿用既有授权。
