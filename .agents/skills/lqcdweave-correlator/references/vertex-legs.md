# 每个顶点每条腿的基底与截断

选择单位是某个测量、顶点和费米子腿。共同 Ne/Np 可作为任务默认，单独覆盖保留实际值、味道、源/汇/流角色、真实端点及有序基底/点集。多粒子各粒子分别标明，重子保留三腿顺序；不将 light/charm 或两条流强制合为一行。

同一实际有序基底的前缀或位置选择才允许共享读取。不同基底、不同顺序和非嵌套选择保留明确映射；选择进入身份、轴、维度、成本和内存核算。I/C 配对和同位旋伙伴的选择须按对称变换一致，不能只凭 Flavor 系数声称截断后保持量子数。

## 任务配置与入口参数

按粒子/角色/腿记录需求，不将配置表伪装成 calculate 已有参数。例如 light 腿 Ne=64、charm 腿 Ne=32 是两条实际选择，不能用一个全局 Ne 代替。点端才展示 Np/坐标/点池共享关系，纯模态任务无需 point 字段。

逐腿选择应沿 `Meson.with_mode_indices` 等当前绑定入口传递并核对真实矩形读取；配置表本身不是接口。未接通的选择需在后端实现和验证，不以历史示例的统一截断限制整个库。

## 已有等时介子模式分块

固定边界的多 cfg 任务若保留 PC，在 cfg 循环外调用 `split_meson_mode_pairs(correlator, partitions=...)`，一次完成符号分块和 PC 投影；该步骤不做 IO。完整通道和径向请求交给一次 `calculate(..., execute=False)`，后续按[联合任务与固定回放](plans.md#联合任务与一次规划反复回放)执行；`partial(calculate, radial, ...)` 仍会每次重新规划，不能当作选路复用。各 cfg 使用各自实际有序基底、当前 reader 和坐标覆盖，不要求不同 cfg 的本征基底身份相同。模态分块不会自动启用时间稀疏化。`calculate(..., partitions=...)` 仍适合单次任务。

同味道中性介子的有序径向项通常不是 C 本征算符。若 `C O_ab = c0 O_ba`，则目标 C 宇称的非对角基为 `(O_ab + (C/c0) O_ba)/sqrt(2)`；对角项仅在 C=c0 时存在。需要完整径向空间时保留对称和反对称基，并分入各自 C 区；不能只按裸算符 c0 标签分区。用带独立 Tag 的物理算符线性组合交给 `Hadron → gen_correlator`，按实际端点绑定正反序模式选择；后端保持紧凑矩阵路径。不同 r 是否混合按物理任务确定，不能替代 C 分区。非同味道带味介子没有物理 C 宇称，不能仅凭 c0 删去混合项。

需要逐项保留有序模式块时，旧方式仍可用：`split_eigenmodes(correlator, partitions=...)` 生成全有序块，再交给同一次 `calculate`；结果可通过 `project_meson_mode_pairs` 组合为 PC 对称块。选择沿相连传播子端点进入真实矩形读取与成本。同一总 `usedNe` 和模式区间不等于任意逐腿 Ne/Np 配置接口。

默认优化策略沿用统一 `calculate`；只有用户要求直接数值对照时才用 `optimize="none"`。
分块数量不自动决定优化器，有限搜索未找到路线不等于数学上不可执行。

范围是等时 dense-V/V 介子图及其适用扫描，包含连通/断开组合；点端、重子、不同时间位移项和 SpectralProfile 联用不从该能力推导为已验收。保留 PC 的交换配对、恢复原函数的权重及完整简并空间要求见[介子本征模分块](../../../../docs/modules/operators/meson_mode_blocks.md)；核对当前公开导出和 `tests/test_mode_block_correlator.py`，不把小规模 CPU 参考作为 GPU/生产规模证据。

## 对角核的径向零块

`Meson.with_mode_indices(...).is_structurally_zero(t)` 只读头信息：实际两端选择不相交，
且未切片核有有效 `structure="diagonal"` 声明时，才能证明该顶点为零。重排、部分重叠、
未知结构或不同实际基底导致对角声明失效时都保留；不扫描数值并按阈值猜零。
结构化关联函数和原生紧凑矩阵会在规划前排除已证明为零的分量，原有输出轴保持不变。
若要缩短输出算符轴，在 `Hadron → gen_correlator` 构造前用同一证明删除整个零算符，
保留其余算符原顺序、线性组合系数和径向来源。未登记结构的历史输入不能仅按名称补标签。
科学定义确认后，历史 V/V reader 可通过 `DatasetElemental(..., elemental_structures=...)`
显式补充 `(sector, component, momentum_slot) → structure` 声明；详见模式分块文档。
声明改变绑定身份，不修改已发布数据，不绕过实际两端基底检查。
基底改变或清理算符后联合重规划一次，不能拿旧档案直接回放不同结构。

## 扩展时的验收

逐腿选择须沿物理端点到 elemental/传播子真实读取，保留 dagger 后槽位、基底身份、具名轴和完整输出。对照独立数值参考检查不同截断、端点、源共轭和共享；不能通过用户手动 load、补零或 reshape 绕过读取/基底检查，也不能将模式分块的零掩码参考当成实际生产实现。


仅专家已持有数组、明确要单时间对连通 profile 矩阵时，按[三层输入路由](../../../../docs/modules/measurements/meson_profile_matrix.md#entry-routing)选择现有数值入口；普通符号/完整测量无需使用它们。
