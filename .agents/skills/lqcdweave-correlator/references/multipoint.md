# 带流多点关联函数

先明确初末态、各流的物理定义、动量、味道和时间顺序。局域流、守恒流及其它插入的端点和数据需求不同，不能仅改名称互换。

## 符号构造

从 `Hadron/Flavor`、已定义的流配方和必要的联合投影构造物理算符，再调用 `gen_correlator`。保留各粒子和流自己的 Tag；需要保留不同时间时按公开符号约定使用 `None`，不把全部插入移到同一锚点。

- 按所用傅里叶与转移动量约定核对动量守恒，逐项列明初态、末态、流动量及耦合目标。
- 守恒流保留每项真实相邻端点、方向和边界处理；锚点时间不能代替完整端点覆盖。
- 重复相同物理流、重合时间和接触项须核对当前支持范围；不能以不同名字伪装成独立流来绕过计数或物理限制。
- 源端 dagger、复系数、味道归一化及所需 Wick 贡献只按物理定义处理一次。裸格点矩阵元不自动附加匹配、电荷、弱系数或单位换算。

## 联合执行

将全部兼容的多点通道、流分量、方向和参数点组成一个嵌套请求，选定一次路径后通过后端回放完整坐标；不逐时间、逐方向重复 `calculate`。实际结构、抽样池关系或包含概率不兼容时才分模板，并记录原因，见[固定回放](plans.md#联合任务与一次规划反复回放)。

通过原有 `Insertion/Operator` 和绑定入口提供介子、重子或流的实际输入。逐腿模式、点集、物理时间、来源、边界及自旋基须匹配；符号构造成功不代表所有输入扇区或设备已验收。接口边界见[数据绑定](binding.md)、[算符](operators.md)和[执行](execution.md)。

正式运行前使用[多点核对表](../../README.md#execution-scope)，共同配置说明一次，源/汇/流的差异逐腿列明；仅实际点端披露点集与抽样权重。
